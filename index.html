Test Outfit-Mesh-Linker Prototype

Attach an outfit mesh to a character's shared skeleton — browser-side workflow.

1. Import models

For best alignment, export the Body and Outfit in the same coordinate space, scale, and rest pose. Keep both files on your device; this prototype processes them in your browser.

2. Model preview

Import a Body and/or Outfit to preview them here.

Drag to rotate · Pinch or scroll to zoom. The preview overlays the imported models; it does not modify either source file.

3. Skeleton & linking checks

Waiting for models. Load a rigged Body to inspect its skeleton, then load the Outfit mesh.

This first prototype checks model structure and alignment only. Automatic surface-weight transfer, shared-skeleton binding, animation preview, and VRM 0.x / 1.0 export are not implemented yet.
